3 key features

1 Daily Mood Check-in

Users log one mood per day with a short note, making the app fast, focused, and easy to use.

2 Weekly Insights

The app shows the week at a glance with averages, trends, and mood distribution so patterns are obvious.

3 Secure Profile Settings

Users can manage profile data and credentials in a clean authenticated area with account controls.

About the project

Better Life was inspired by a simple problem: people remember the highlight of a week, but not the emotional pattern behind it. A quick daily log turns vague memory into something measurable. This project was built as a Holberton School Portfolio Project, and it focuses on helping users understand themselves through small, consistent check-ins.
